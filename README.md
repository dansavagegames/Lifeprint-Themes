# Lifeprint-Themes
A Tampermonkey script to give themes to the Lifeprint website.

# How to Use
1. Go to [LifeprintThemes.user.js](https://github.com/dansavagegames/Lifeprint-Themes/blob/main/LifeprintThemes.user.js)
2. On your keyboard, type "CTRL+A" (should highlight all) then "CTRL+C" (to copy)
3. If Tampermonkey is not already installed, install it
4. Click on the Tampermonkey extension
5. Hit "Dashboard"
6. Tap the little "+" to the left of "Installed Userscripts"
7. On your keyboard, type "CTRL+A" (highlight all) then "CTRL+V"

Now you may either hit "CTRL+S" on your keyboard to save Lifeprint-Themes, or click "File", and in the dropdown, "Save".

The script is now installed.

8. Copy any of the desired themes into `var colorScheme = "";`
9. Save again ("CTRL+S" / File > Save)

And you should have [Lifeprint](https://www.lifeprint.com/) themed to your liking. Enjoy!
